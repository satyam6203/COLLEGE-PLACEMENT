## Priority Recommendations

**Easy Priority:** Problems 1, 4, 7, 8, 10, and 15. They teach the basic traversal patterns you'll reuse in harder questions.

**Medium Priority:** 17, 24, 26, 27, 29, 30, 41, 42, 43, 51, 53, and 55. These cover most of the core patterns interviewers expect.

**Approach:** Solve in order of topic and difficulty rather than randomly. Master one pattern before moving to the next.

## Patterns to Master

- **Traversal**: BFS, DFS (recursive & iterative)
- **Components**: Connected components, number of islands
- **Cycle Detection**: Undirected (DFS/DSU), Directed (DFS with recursion stack / Kahn's)
- **Bipartiteness**: BFS/DFS coloring
- **Topological Sort**: Kahn's algorithm (BFS), DFS-based
- **Shortest Paths**: BFS (unweighted), Dijkstra's, Bellman-Ford, 0-1 BFS, Floyd–Warshall
- **Disjoint Set Union (DSU)**: Find/Union with path compression & union by rank
- **MST**: Kruskal's algorithm, Prim's algorithm
- **Advanced**: Tarjan's (bridges/articulation points), Eulerian paths/circuits, Hierholzer's algorithm
